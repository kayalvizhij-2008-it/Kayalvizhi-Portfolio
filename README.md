# Kayalvizhi J — The Developer Series

A cinematic, streaming-inspired portfolio for **Kayalvizhi J**, Software Engineer | AI/ML Developer.

> "Engineering Intelligence. Building What's Next."

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

Production build:

```bash
npm run build
npm run preview
```

## Content

All content lives in `src/data/portfolio.ts`. Update projects, profile, skills, experience, education there.

## Assets

- Resume: replace `public/assets/Kayalvizhi_J_Resume.pdf`.
- Photo: replace `pic1.jpeg` and `pic.png`, then run `npm run images`.

## Environment

No secrets required. GitHub data is fetched from the public API with graceful fallback.

## Features

- Cinematic opening sequence
- Profile selector
- Hero with parallax portrait
- Featured projects (My Originals) with case studies
- Complete searchable project library (40 repositories)
- Skills, experience, education
- GitHub activity
- Resume viewer
- Contact form (mailto)
- Command palette (Ctrl+K)
- Reduced-motion support
